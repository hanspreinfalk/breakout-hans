# 🎮 Breakout - Juego en JavaScript

## 🎯 Propósito

Este proyecto tiene como objetivo poner en práctica los conceptos básicos del desarrollo de videojuegos utilizando JavaScript, HTML y CSS. Está basado en el juego clásico *Breakout* y reutiliza la lógica de *Pong* vista en clase.

---

## 🕹️ Instrucciones para jugar

- **Controles del juego:**
  - Usa las **flechas izquierda y derecha** del teclado para mover la paleta.
- **Objetivo:**
  - Destruye todos los bloques de colores usando la pelota para ganar el juego.

---

## 📜 Reglas del juego

- Puedes configurar el **número de renglones y columnas** de bloques.
- Cada vez que la pelota golpea un bloque, este se destruye.
- Se muestra en pantalla el **número de bloques destruidos**.
- La pelota **rebota** en los bordes izquierdo, superior y derecho.
- Si la pelota **cae por el borde inferior**, pierdes una vida.
- Tienes **3 vidas** en total.
- Cuando destruyes todos los bloques, **ganas el juego**.
- Si pierdes todas las vidas, aparece un **letrero de GAME OVER**.
